Diperlukan untuk analisis AI speaking kamu

🤖
Tes ini menggunakan Gemini AI dari Google untuk mengevaluasi speaking kamu secara otomatis. Sistem ini menggunakan model BYOK — kamu membawa API key sendiri yang gratis dan tidak disimpan di server kami.
Cara Mendapatkan API Key Gratis
  • 1 Buka Google AI Studio (login dengan akun Google)
  • 2 Klik "Create API Key" → pilih project atau buat baru
  • 3 Copy API key yang dihasilkan dan paste di bawah ini
🔒 Key tidak disimpan di database kami — hanya dipakai saat analisis berlangsung dan langsung dihapus dari memori.
